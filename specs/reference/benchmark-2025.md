## 分級規則

原始報表定義:

```
A級 <10%    B級 10~25%    C級 25~50%    D級 50~75%    E級 75~90%    F級 >90%
```

### 關鍵性質(實作必讀)

**百分位欄位的順序固定是「最佳 → 最差」,不是數值大小順序。**

指標方向不同,數值走向就相反:

| 指標 | 10% 欄(最佳) | 90% 欄(最差) | 方向 |
|---|---|---|---|
| 母豬年產離乳仔豬數 | 25.65 | 18.24 | 越高越好 |
| 離乳前死亡率 | 8.77 | 24.38 | 越低越好 |
| 母豬非生產天數 | 39.89 | 83.65 | 越低越好 |

因此**指標方向可由資料自行推導**:比較第一欄與最後一欄的大小即可,不需要另外維護一份方向對照表。

### 邊界處理

採**嚴格不等式**。數值剛好等於切點時,歸入較差的一級。

驗證案例:合億畜牧場「離乳前死亡率 20.21」恰好等於 75% 切點(20.21),官方判定為 **E 級**(較差側),而非 D 級。

### 演算法

```
方向 = (第一欄 > 最後一欄)          # true 表示越高越好
對每個切點 (10→A, 25→B, 50→C, 75→D, 90→E):
    若 方向 為真 且 本場值 > 該切點  → 回傳該等級
    若 方向 為假 且 本場值 < 該切點  → 回傳該等級
全部不符 → 回傳 F
```

此演算法已用合億畜牧場 18 項已知評級全數驗證通過。

## 指標定義與改善方向

取自原始報表,供 AI 解讀時引用。

| 指標 | 定義 | 改善方向 |
|---|---|---|
| 母豬年產離乳仔豬數 (PSY) | 母豬每年離乳仔豬數,代表母豬畜群對豬場的實際貢獻,常用於產業成績比較 | 改善母豬年產胎數與母豬平均離乳仔豬數 |
| 母豬年產胎數 | 365.25 天扣除非生產天數後,除以母豬生產天數(懷孕+哺乳) | 減少非生產天數與平均哺乳天數 |
| 母豬非生產天數 | 每頭母豬年度內未進行生產工作的日數,反映生產效率與經濟效益 | 增加有效配種以提升分娩率,或盡速淘汰空胎母豬 |
| 分娩率 | 母豬配種後實際分娩的比率。台灣正常值應在 75%~85% | 運用公豬在前使發情母豬站立穩定配種,標準化操作流程 |
| 重發情配種佔比 | — | 外購或增加指定配種培育更多女豬,盡速更替此族群母豬 |
| 離乳至第一次配種間隔 | 母豬離乳後至第一次配種的天數 | 接近或超過 7 天時,檢視哺乳期採食量與照護程序 |
| 母豬年產活仔數 | 綜合窩均活仔數、分娩率與分娩指數 | 提升窩均活仔數與年產胎數 |
| 窩均總仔數 | 母豬懷孕仔豬胎數的最大值,代表繁殖潛能 | 引入高繁殖品種 |
| 窩均活仔數 | 母豬分娩後存活仔豬數量,代表可飼育最高數值 | 與總仔數及產程照護高度相關 |
| 離乳前死亡率 | 哺乳期間損失的仔豬比例,隨畜舍型態、管理模式與母性表現而異 | 提升母豬哺乳能力或母性篩選;短期可增加採食量、加強巡視以減少壓死 |
| 母豬平均離乳仔豬數 | 母豬平均每胎實際離乳仔豬數量 | 與窩均活仔數及離乳前死亡率高度相關 |

## 輸入合理值範圍(供 US-2 驗收條件 2 使用)

範圍取常模 10%~90% 區間再放寬,超出即視為明顯不合理,計算前擋下。
不是「不可能發生」,是「不像正常填報,先請使用者確認」。

| 指標 | 合理下限 | 合理上限 | 說明 |
|---|---|---|---|
| 分娩率 (%) | 30 | 100 | 100% 為理論上限 |
| 離乳前死亡率 (%) | 0 | 60 | 超過 60% 幾乎必為填報錯誤 |
| 重發情配種佔比 (%) | 0 | 60 | |
| 母豬死亡百分比 (%) | 0 | 30 | |
| 母豬出售百分比 (%) | 0 | 100 | |
| 懷孕天數 | 108 | 120 | 生理範圍,非常模範圍 |

| 平均仔豬離乳日齡 | 14 | 42 | 同上 |

| 母豬年產胎數 | 1.5 | 2.6 | 理論上限受懷孕天數限制 |
| 母豬非生產天數 | 0 | 150 | |

跨欄一致性檢查(對應 US-2 驗收條件 3):

```
窩均活仔數 ≤ 窩均總仔數                     — 違反時提示,不阻擋
母豬平均離乳仔豬數 ≤ 窩均活仔數              — 違反時提示,不阻擋
母豬年產胎數 ≈ 365.25 / (哺乳天數 + 懷孕天數)  — 誤差超過 ±10% 時提示
```

## 規模型指標的呈現方式(供 US-3 驗收條件 3 使用)

「規模型數值」(總配種數、分娩窩數、總產仔數等,見上方章節)不評級,但仍顯示,格式為:

```
本場輸入值   |   全國中位數   |   全國平均
(不顯示級距色塊、不顯示 A~F 字母、不畫在雷達圖上)
```

這類數字只用來讓使用者確認資料填對了(數量級對不對),不作為經營效率的判斷依據——
效率判斷交給窩均活仔數、PSY 等比率型指標。

## 衍生公式

原始報表註解提供,實作時作為交叉驗證用:

```
分娩指數     = 365.25 / 經產母豬平均分娩間隔期
母豬年產胎數 = (365.25 - 母豬平均非生產日) / (平均哺乳天數 + 平均懷孕天數)
每窩平均離乳仔豬數 = 離乳仔豬數 / 扣除離乳仔豬數為 0 的母豬數量
```

「母豬年產離乳仔豬數」的母豬包含新女豬及經產母豬。
